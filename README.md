# NEXO AI MVP

MVP inicial do NEXO AI.

## Stack
- React + Vite + TypeScript
- Supabase
- Evolution API via Supabase Edge Functions

## Objetivo do primeiro marco
Receber uma mensagem do WhatsApp, registrar no Supabase, identificar o cliente e preparar uma resposta automática.

## Segurança
Nunca commitar chaves privadas, service_role ou API keys da Evolution.
